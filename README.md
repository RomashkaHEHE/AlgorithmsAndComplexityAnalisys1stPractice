# Практика 1. Анализ сложности

Сравнение BubbleSort и QuickSort на случайных и обратных массивах.

- `src/main/java/ru/urfu/algorithms/Sorts.java` — сортировки.
- `src/main/java/ru/urfu/algorithms/Benchmark.java` — измерения времени.
- `src/test/java/ru/urfu/algorithms/SortsTest.java` — проверки.
- [Результаты и графики](results/REPORT.md).

Запуск из папки проекта (нужны JDK 17+, Python и Matplotlib):

```powershell
python -m pip install -r requirements.txt
powershell -ExecutionPolicy Bypass -File .\run.ps1
```
